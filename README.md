# A Esta Es - Semana Santa Mérida

Aplicación web minimalista que muestra una cuenta atrás dinámica para la Semana Santa de Mérida. El proyecto calcula matemáticamente la fecha de la próxima Semana Santa de forma perpetua, actualizando el estado de la página automáticamente sin necesidad de mantenimiento manual.

## Funcionalidades Principales

* Cálculo algorítmico (Meeus/Jones/Butcher) del Domingo de Resurrección para cualquier año.
* Cuenta atrás precisa en días, horas, minutos y segundos.
* Cambio dinámico de interfaz: fondo fotográfico durante la espera y colores específicos según el día durante la Semana Santa.
* Enlaces directos a la información de las Hermandades y Cofradías de Mérida mediante sus escudos.
* Diseño completamente adaptativo (responsive) para dispositivos móviles y navegadores de escritorio.
* Ventana modal informativa con la nota legal.

## Tecnologías Utilizadas

* HTML5
* CSS3 (Animaciones, filtros, Flexbox, Media Queries)
* JavaScript puro (Vanilla JS para cálculo de fechas y manipulación del DOM)
